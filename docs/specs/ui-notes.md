# UI 仕様メモ(v0.1 プロトタイプ)

UIイメージ(仕様確定用プロトタイプ)に付いていた開発用の注記をここに移したもの。
**アプリ画面には表示しない。** 実装を変更するときは、この制約を崩していないか確認する。

## レイアウト(MTG 7/30)

- タブは **ホーム / 壁打ち / 自分史** の3つ。履歴はタブから外し、全画面共通ヘッダーの
  ☰ ドロワーからアクセスする——「どれだったか」を答えるだけの画面に、下部バーの
  1/3 を常設する必要はない
- ヘッダーは `components/AppHeader.tsx`。☰(履歴ドロワー)/ タイトル / ＋(新規壁打ち)を
  全画面で常時表示する。会話の中からしか新規作成と過去参照に行けないのは、
  どちらも「会話していないとき」に探すものなので逆だった
- シェルは可視領域ちょうどの高さに固定する(`--sc-app-height`)。`100dvh` はキーボードを
  勘定に入れない——iOS のレイアウトビューポートは縮まないため。縮むのは visual viewport の
  ほうなので、そちらを読んで CSS 変数に流している(`components/viewport-height.tsx`)
- `viewport-fit: cover` + `env(safe-area-inset-*)`。ヘッダーはノッチ、タブバーと
  ドロワーはホームインジケータを避ける

## ① オンボーディング

- 初回アンケートで文脈(大学・部活・志望等)を取得し、システムプロンプトに自動反映。学生はプロンプトを書かない
- 選択肢チップ主体で入力負荷を最小化(B層=やり方がわからない層への配慮)。ただし壁打ち本編はテキスト入力主軸を維持
- 回答は `profiles` / オンボーディングテーブルに保存し、後から設定で変更可能

## ② 壁打ち

- スタイル切替は**トーンのみ**を変える。抽象語→具体化要求は全モード共通の不可侵仕様(企画書 4.1)
- トーンは**メニューバーのプルダウン**で選ぶ(MTG 7/30)。ドロワーの奥に一度だけ出す
  形はやめた——見つからないし、選んだ側と選ばなかった側の違いも分からなかった
- **セッション途中では変更できない**という制約は変わらない。途中で切り替えると、
  モデルに渡す履歴が二つのトーンの混在になり、その履歴を生んだ指示と一致しなくなる。
  なので切替は新規セッションの作成になり、確認ダイアログでそう伝えてから実行する
- 「今日のテーマ」のヘッダー表示は廃止(MTG 7/30)。テーマはシステムプロンプトには
  残っている——画面の一等地で会話中の学生に主題を宣言するのをやめただけ
- 「モードで変わるのは言い方だけ…」の注記も廃止。二つのトーンの区別に注記が要るなら、
  直すべきは注記のほうではない
- トーンの中身は実利用のフィードバックで書き直した(MTG 7/30)。
  じっくりは受け止めを返答の大半にし、不足の指摘・評価・逆接の前置きを禁止。
  ストレートは批評の対象を「いま出てきた一文」に限定し、人格否定・嘲笑・
  「面接で通用しない」という言い方を禁止した——後者は指摘ではなく脅しだった。
  **`prompts/modes/tones.ts` の `TONE_CONTRAST_EXAMPLES` が仕様**。同じ学生の発話に
  両トーンで答えた対を並べてある。縦に読めばトーンらしさ、横に読めば深さが同じかを見る
- AIは結論を先に出さず、共感+**必ず次の問い**を添える
- 上部の対話テーマは初回はガイド付き(答えやすい問いから段階的に深掘り)
- **STAR 抽出は自動**(MTG 7/30)。「セッションを終える」ボタンは廃止した——
  押されなければ 自分史 が空のままになる操作を、学生の側に残していたため。
  走るのは (a) 別セッションへ切替時 (b) 新規チャット作成時
  (c) 最後の抽出から6メッセージ以上増えた状態でアプリ復帰時。
  同じセッションを何度も読むので、既存エピソードのタイトルをモデルに渡して
  「まだ残していないもの」を求め、それでも似たものが返ったら新規作成ではなく更新する
  (`apps/web/lib/extraction.ts` / `apps/web/lib/similarity.ts`)

## ③ 履歴

- セッションは自動保存。タップで途中から再開できる(対話が単発で消費されない)
- 抽出済みエピソードがあるセッションにはバッジを表示し、自分史との紐付けを可視化

## ④ 自分史

- **年表が先**(MTG 7/30)。高校以前〜大学4年の枠は、エピソードが0件でも白紙で描く。
  カード一覧は「すでにあるもの」しか映さないので、2件しか無い学生には
  「何が足りないか」が一切見えなかった。空欄は指示になるが、空の画面は何も言わない
- 年表の項目をタップすると、下の該当カードを開いてそこへスクロールする。
  年表は場所を示すもので、本人の言葉が置いてあるのはカードのほう
- 時期は抽出時にモデルが決める(`period`)。語られていなければ「不明」で、推測はしない。
  置き直しはカードの編集からできる
- 全エピソードを STAR + 学び + 感情で構造化。雑なテキストで保存しない
- 本人の所有感を担保: 編集・削除・(v0.2)Markdown エクスポート
- カードの言葉はすべて学生本人の発話から抽出(AIの要約文体にしない)
