# UI 仕様メモ(v0.1 プロトタイプ)

UIイメージ(仕様確定用プロトタイプ)に付いていた開発用の注記をここに移したもの。
**アプリ画面には表示しない。** 実装を変更するときは、この制約を崩していないか確認する。

対応する実装:

| 画面 | ルート | ファイル |
| --- | --- | --- |
| ① オンボーディング | `/onboarding` | `apps/web/app/onboarding/page.tsx` |
| ② 壁打ち | `/chat` | `apps/web/app/(main)/chat/page.tsx` |
| ③ 履歴 | `/history` | `apps/web/app/(main)/history/page.tsx` |
| ④ 自分史 | `/jibunshi` | `apps/web/app/(main)/jibunshi/page.tsx` |

## ① オンボーディング

- 初回アンケートで文脈(大学・部活・志望等)を取得し、システムプロンプトに自動反映。学生はプロンプトを書かない
- 選択肢チップ主体で入力負荷を最小化(B層=やり方がわからない層への配慮)。ただし壁打ち本編はテキスト入力主軸を維持
- 回答は `profiles` / オンボーディングテーブルに保存し、後から設定で変更可能

## ② 壁打ち

- スタイル切替は**トーンのみ**を変える。抽象語→具体化要求は全モード共通の不可侵仕様(企画書 4.1)
- AIは結論を先に出さず、共感+**必ず次の問い**を添える
- 上部の対話テーマは初回はガイド付き(答えやすい問いから段階的に深掘り)
- セッション終了ボタンで STAR 構造の自動抽出へ遷移

## ③ 履歴

- セッションは自動保存。タップで途中から再開できる(対話が単発で消費されない)
- 抽出済みエピソードがあるセッションにはバッジを表示し、自分史との紐付けを可視化

## ④ 自分史

- 全エピソードを STAR + 学び + 感情で構造化。雑なテキストで保存しない
- 本人の所有感を担保: 編集・削除・(v0.2)Markdown エクスポート
- カードの言葉はすべて学生本人の発話から抽出(AIの要約文体にしない)
